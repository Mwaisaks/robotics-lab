# Pitch: Robo, data and privacy (Rebecca)

For the AI / data / privacy part of the slides. Honesty rule: we only claim what the build does.

## ROBO, THE AI TUTOR
- Every mistake gets an explanation of WHY, not just "wrong"
- Instant built-in hint (works offline), then a personal AI hint if online
- English and Kiswahili, in simple words for ages 12–18
- 23 built-in hints per language across Sort, Program, Light it up and the Microcontroller lab
- If the AI is slow or offline, the built-in hint stays, so a student is never left without help

## HOW THE DATA WORKS
- Student enters a class code + nickname. No accounts, no passwords.
- Results are saved on the device first, then synced when there's internet
- Teacher enters the class code → sees stars, time per level, and the class's top 3 mistakes

## PRIVACY (designed for minors)
- Nicknames only: no real names, photos, phone numbers or location
- Nicknames are never sent to the AI. Only the level and mistake type are.
- Students can only add results; nobody can list or download other classes
- API keys stay on the server, never in the app

## WHAT A TEACHER CAN MEASURE
- Who finished each level, how fast, and with how many stars
- Which mistakes the whole class keeps making, so they know what to reteach
